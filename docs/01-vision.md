# Vision

One system, running on the lab's own R730 server, that runs the AI Lab
end to end: who's here (attendance), what they should learn (curriculum),
what they did (exercises, exams), and proof of it all (progress records,
verification IDs). Teacher console + projector wall make the room feel
like a living system.

Build order: **Exams -> Attendance -> Settings**, then the rest.
Philosophy: "Command AI, don't depend on it." Mastery gate: 82%.
Single lab now; `labId` on users/PCs keeps the door open for all 8 labs.
